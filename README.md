# want-a-break-from-the-ads?
This is a basic music player app that uses YouTube's Data API to receive the users playlists and videos attached to their account.

Project is currently hosted here: [`https://music-player-sveltekit-production.up.railway.app`](https://music-player-sveltekit-production.up.railway.app).

App is currently in testing, for whitelisting or preview, toss me an email at [`asfarj@proton.me`](asfarj@proton.me).
